# Dashboard Analítico de Vendas

Projeto desenvolvido para a disciplina de Visualização de Dados.

## 🚀 Como Executar
1. Clone o repositório.
2. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```
3. Execute a aplicação:
   ```bash
   streamlit run app.py
   ```

## 🛠️ Tecnologias
- **Python 3.x**
- **Streamlit** (Interface e Interatividade)
- **Plotly** (Gráficos Interativos)
- **Pandas** (Manipulação de Dados)

## 📂 Estrutura
- `app.py`: Código principal da aplicação.
- `data/vendas.csv`: Dataset de vendas.
- `docs/`: Documentação de arquitetura e testes.
- `requirements.txt`: Dependências do projeto.
